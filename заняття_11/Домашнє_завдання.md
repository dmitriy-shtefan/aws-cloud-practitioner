### Завдання: обрати сервіси безпеки та governance для навчального порталу

Уявіть, що потрібно забезпечити безпеку навчального порталу в AWS та організувати управління його акаунтами.

Для кожної потреби оберіть один відповідний сервіс або інструмент і письмово поясніть вибір:

1. Ключ для шифрування документів у S3.
2. Пароль бази даних із регулярною автоматичною зміною.
3. Адреса API тестового середовища поза кодом застосунку.
4. Блокування вебзапитів з ознаками SQL injection.
5. Захист доступності від DDoS.
6. Виявлення підозрілих з'єднань EC2.
7. Пошук відомих вразливостей у встановлених пакетах.
8. Пошук персональних даних у файлах S3.
9. Спільний огляд findings від кількох сервісів.
10. Отримання звіту SOC про AWS.
11. Об'єднання акаунтів розробки та виробничого середовища.
12. Заборона вимикати GuardDuty в member accounts певної OU.

Що потрібно здати: таблицю з трьома стовпцями: потреба, сервіс або інструмент, пояснення вибору одним реченням.

Підказка: матеріал [Безпека та governance в AWS](Безпека_та_Governance.md) містить одну відмінну задачу для кожного сервісу. 
Особливу увагу варто приділити відмінностям між KMS, Secrets Manager і Parameter Store, а також між GuardDuty, Inspector і Macie.

Для самоперевірки: [20 тестових питань до заняття 11](Questions_11.md).
