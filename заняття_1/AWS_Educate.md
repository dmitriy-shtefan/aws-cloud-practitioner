# Реєстрація в AWS Educate та огляд навчальної платформи

У цій практичній роботі ви створите безкоштовний learner account в AWS Educate, познайомитеся з каталогом курсів і знайдете перший курс для вивчення основ AWS Cloud.

Усі дії виконуються у браузері.

Основні кроки можна виконати приблизно за 15 хвилин. Якщо лист підтвердження надходить із затримкою або ви вперше працюєте з навчальною платформою, знадобиться трохи більше часу.

---

## 1. Що буде зроблено

Після виконання практики у вас буде:

1. Безкоштовний learner account в AWS Educate.
2. Підтверджена email-адреса.
3. Пароль для входу в AWS Educate.
4. Розуміння структури каталогу курсів і лабораторних робіт.
5. Знайдений і відкритий початковий курс про AWS Cloud.
6. Обраний наступний навчальний крок.

Рекомендований результат:

```text
AWS Educate account -> Introduction to Cloud 101 -> перший навчальний модуль
```

Якщо курс `Introduction to Cloud 101` відсутній у поточному каталозі, оберіть перший foundational course у секції `Getting Started`.

---

## 2. Чому для цієї практики використовується AWS Educate

Звичайний AWS account призначений для створення реальних cloud resources і містить billing information. Під час його реєстрації можуть знадобитися платіжні дані.

AWS Educate — це окрема навчальна платформа для початківців і школярів.

AWS Educate дає змогу:

- зареєструватися за допомогою email;
- навчатися безкоштовно;
- проходити self-paced courses;
- виконувати hands-on labs у контрольованому середовищі;
- відстежувати прогрес;
- отримувати digital badges за окремі курси.

AWS вказує, що AWS Educate доступний учням від 13 років у більшості країн. 

---

## 3. Не плутайте AWS account, AWS Builder ID та AWS Educate account

Це різні типи облікових записів.

| Обліковий запис | Для чого потрібен | Чи використовуємо зараз |
| --- | --- |-------------------------|
| AWS account | Створення S3 buckets, EC2 instances, databases та інших реальних AWS resources; має billing | Ні                      |
| AWS Builder ID | Особистий профіль для окремих AWS developer і training services | Ні, у цій практиці      |
| AWS Educate learner account | Безкоштовні курси та навчальні labs для початківців | Так                     |

Актуальний FAQ AWS Educate описує різні процеси входу:

- learner віком 18 років або старше використовує AWS Builder ID;
- learner молодше 18 років підтверджує email, задає пароль і входить безпосередньо в AWS Educate.

Тому в цій практиці не потрібно окремо створювати AWS Builder ID.

AWS Skill Builder — це інша велика бібліотека професійних AWS training materials.

## 4. Важливі правила безпеки

Під час реєстрації та навчання:

- не повідомляйте пароль викладачу;
- не надсилайте verification code у чат;
- не публікуйте email і дату народження у GitHub;
- не додавайте персональні дані до лабораторних завдань;
- не використовуйте один пароль для AWS Educate, email і соціальних мереж;
- не вводьте банківську картку;
- не переходьте за підозрілими посиланнями з неочікуваних листів.

Для AWS Educate платіжна картка не потрібна. Якщо сторінка просить додати billing information або payment method, зупиніться: найімовірніше, ви потрапили на сторінку створення звичайного AWS account.

Правильна сторінка реєстрації має адресу на домені:

```text
awseducate.com
```

## 5. Попередні умови

Перед початком переконайтеся, що у вас є:

1. Ноутбук або компʼютер.
2. Доступ до інтернету.
3. Актуальна версія Chrome, Firefox, Edge або Safari.
4. Особиста email-адреса, до якої ви маєте доступ.
5. Можливість відкрити лист і перейти за посиланням підтвердження.

Не використовуйте тимчасову email-адресу. Вона знадобиться для подальшого входу, відновлення пароля та отримання badges.

Для реєстрації краще використовувати звичайне вікно браузера. AWS Educate попереджає, що частина навчального контенту може не працювати в private або incognito mode.

## 6. Як відкрити правильну сторінку AWS Educate

1. Відкрийте браузер.
2. Перейдіть на офіційну сторінку:

```text
https://aws.amazon.com/education/awseducate/
```

3. Знайдіть кнопку:

```text
Register now
```

4. Натисніть її.
5. Перевірте, що відкрилася форма з заголовком:

```text
Create your account
```

Можна також відкрити форму реєстрації напряму:

```text
https://www.awseducate.com/registration/s/registration-detail
```

Якщо ви вже маєте AWS Educate learner account, не створюйте другий. Натисніть `Sign in` і перейдіть до розділу 10 цієї інструкції.

---

## 7. Як заповнити форму реєстрації

Форма містить персональні дані.

### Крок 1. Імʼя та прізвище

Заповніть поля:

```text
First name
Middle name - optional
Last name
```

У `First name` введіть імʼя.

У `Last name` введіть прізвище.

Поле `Middle name` необовʼязкове. Його можна залишити порожнім.

Використовуйте справжні дані. Це особливо важливо, якщо пізніше ви захочете отримати digital badge.

### Крок 2. Країна та місто

У полі `Country` оберіть країну проживання.

Наприклад:

```text
Ukraine
```

Після вибору країни може стати доступним поле:

```text
State or province
```

Якщо воно обовʼязкове, оберіть свою область. Якщо поле недоступне або необовʼязкове, переходьте далі.

У полі `City` введіть назву міста.

### Крок 3. Вік

Заповніть:

```text
Birth month
Birth year
```

Вкажіть справжні місяць і рік народження.

Не збільшуйте вік, щоб отримати інший тип account. AWS використовує вік, щоб обрати правильний процес реєстрації та доступні функції.

Для learners молодше 18 років недоступні Job Board та Emerging Talent Community. Курси, labs і можливість отримувати badges залишаються доступними.

### Крок 4. Email

У полі `Email` введіть особисту email-адресу.

Перед переходом далі перевірте:

1. Чи немає зайвих пробілів.
2. Чи правильно написаний домен.
3. Чи маєте ви доступ до цієї поштової скриньки.

Приклад формату:

```text
student@example.com
```

Не використовуйте цей приклад як справжню адресу.

### Крок 5. Навчальна програма

Знайдіть поле:

```text
What program(s) are you associated with?
```

Оберіть варіант, який найточніше описує вашу ситуацію. Це має бути студентський, шкільний або загальний learner option — залежно від варіантів, які показує форма.

Не обирайте `Recruiter`. Реєстрація recruiter призначена для роботодавців.

### Крок 6. Мова

У полі `Language` оберіть зручну доступну мову.

Для цього курсу рекомендується:

```text
English
```

Це також допоможе звикнути до англійських назв AWS services, які використовуються на сертифікаційному іспиті.

### Крок 7. Registration code

Поле:

```text
Registration code - optional
```

є необовʼязковим (залиште поле порожнім).

### Крок 8. Умови та маркетингові повідомлення

Перед створенням account:

1. Відкрийте й прочитайте `AWS Learner Terms and Conditions`.
2. За потреби ознайомтеся з `AWS Privacy Notice`.
3. Зверніть увагу на checkbox про отримання AWS news and offers.

Згода на рекламні та маркетингові повідомлення не є навчальним завданням. Не вмикайте її, якщо не хочете отримувати такі повідомлення.

### Крок 9. Створення account

Ще раз перевірте email, країну та рік народження.

Потім натисніть:

```text
Create account
```

На сторінці може зʼявитися CAPTCHA. Виконайте її самостійно за інструкцією на екрані.

---

## 8. Як підтвердити email

Після надсилання форми AWS Educate має надіслати verification email.

1. Відкрийте поштову скриньку, яку вказали під час реєстрації.
2. Знайдіть лист від AWS Educate.
3. Відкрийте лист.
4. Натисніть посилання або кнопку підтвердження email.

Лист зазвичай надходить протягом кількох хвилин.
Якщо листа немає, не створюйте одразу ще один account. Спочатку виконайте рекомендації з розділу 17.

---

## 9. Як створити пароль для learner молодше 18 років

Після підтвердження email AWS Educate запропонує задати пароль.

Створіть унікальний пароль, який:

- не використовується на інших сайтах;
- не містить імені або року народження;
- є достатньо довгим;
- відповідає вимогам, показаним на сторінці.

Добрий підхід — використати кілька випадкових слів, цифри та спеціальні символи або згенерувати пароль через password manager.

Не використовуйте приклади з цієї інструкції як свій пароль.

Після збереження пароля поверніться до AWS Educate.

AWS може запропонувати створити або використати AWS Builder ID. У такому разі дотримуйтеся процесу на екрані й використовуйте ту саму email-адресу, яку вказали у формі AWS Educate.

## 10. Як увійти в AWS Educate

1. Відкрийте:

```text
https://www.awseducate.com/
```

2. Натисніть:

```text
Sign in
```

3. Використайте email і пароль, створені під час реєстрації.
4. Після входу переконайтеся, що відкрився learner dashboard.

Додайте сторінку AWS Educate у bookmarks браузера, щоб наступного разу не шукати посилання через пошукову систему.

## 11. Огляд learner dashboard

Назви й розташування елементів можуть трохи змінюватися, але на dashboard зазвичай доступні:

- рекомендовані курси;
- `Getting Started`;
- каталог курсів;
- badged courses;
- курси, які вже розпочато;
- поточний прогрес;
- пошук і фільтри.

Виконайте короткий огляд:

1. Знайдіть головну сторінку або `Home`.
2. Знайдіть каталог усіх курсів.
3. Знайдіть секцію `Getting Started`.
4. Знайдіть список розпочатих або enrolled courses.
5. Знайдіть індикатор progress.
6. Знайдіть пошук за назвою курсу.
7. Знайдіть профіль або меню account у верхньому правому куті.

Не змінюйте налаштування профілю без потреби.

## 12. Як знайти перший курс

У пошуку каталогу введіть:

```text
Introduction to Cloud 101
```

Якщо курс знайдено:

1. Відкрийте його картку.
2. Прочитайте короткий опис.
3. Знайдіть рівень складності.
4. Знайдіть орієнтовну тривалість.
5. Перевірте, чи містить курс hands-on lab.
6. Перевірте, чи можна отримати badge.

Якщо `Introduction to Cloud 101` не відображається, відкрийте секцію `Getting Started` і оберіть foundational course з основ cloud computing.

Каталог AWS Educate оновлюється, тому назви, картки та порядок курсів можуть змінюватися.

---

## 13. Як розпочати курс

1. На сторінці курсу натисніть кнопку початку або реєстрації.

Залежно від поточного інтерфейсу вона може називатися:

```text
Enroll
Start learning
Get started
```

2. Відкрийте перший навчальний модуль.
3. Знайдіть список тем або course outline.
4. Пройдіть вступний екран.
5. Переконайтеся, що курс зʼявився серед ваших enrolled або in-progress courses.

Під час першого заняття не обовʼязково завершувати весь курс. Мета — зареєструватися, навчитися орієнтуватися на платформі й розпочати перший модуль.

## 14. Дослідження каталогу

Знайдіть у каталозі по одному курсу або lab для кожної категорії:

| Категорія | Що шукати | Приклад AWS service |
| --- | --- | --- |
| Storage | курс про зберігання файлів | Amazon S3 |
| Compute | курс про virtual servers | Amazon EC2 |
| Networking | курс про cloud network | Amazon VPC |
| Databases | курс про database | Amazon RDS або DynamoDB |
| Cloud Operations | курс про monitoring або cost estimation | Amazon CloudWatch або AWS Pricing tools |

Для кожного знайденого курсу усно дайте відповіді:

1. Яку проблему вирішує цей AWS service?
2. Курс foundational чи intermediate?
3. Чи містить курс lab?
4. Скільки приблизно часу він займає?
5. Який курс ви хотіли б пройти після `Introduction to Cloud 101`?

Не потрібно записувати персональні дані або робити скриншоти профілю.

## 15. Як працюють hands-on labs в AWS Educate

AWS Educate labs запускаються в контрольованому навчальному середовищі.

Під час lab AWS може надати:

- тимчасовий доступ до AWS Management Console;
- тимчасові credentials;
- покрокові інструкції;
- обмежений набір AWS services;
- автоматичну перевірку виконаних кроків;
- обмежений час сесії.

Такий lab не є вашим особистим AWS account.

Під час виконання lab:

1. Запускайте середовище тільки кнопкою всередині course або lab.
2. Використовуйте лише credentials, які надав lab.
3. Не вводьте особистий пароль AWS Educate в AWS Management Console lab.
4. Виконуйте тільки дії, описані в інструкції.
5. Не додавайте особисті файли або конфіденційні дані.
6. Слідкуйте за таймером сесії.
7. Завершуйте lab перед закриттям сторінки, якщо є кнопка `End Lab`.

Якщо lab відкриває AWS Management Console, можна звернути увагу на:

- пошук AWS services;
- перемикач region;
- імʼя тимчасового користувача;
- навігацію між сервісами.

Не виходьте за межі завдання lab.

## 17. Часті проблеми

### Проблема: AWS Educate просить банківську картку

Ви, ймовірно, відкрили реєстрацію звичайного AWS account.

Що зробити:

1. Не вводьте платіжні дані.
2. Закрийте цю сторінку.
3. Відкрийте:

```text
https://aws.amazon.com/education/awseducate/
```

4. Натисніть `Register now`.

---

### Проблема: не надійшов verification email

Що зробити:

1. Зачекайте приблизно пʼять хвилин.
2. Перевірте папки `Spam`, `Junk` і `Promotions`.
3. Знайдіть листи за словами `AWS Educate`.
4. Перевірте, чи правильно ввели email.
5. Якщо лист у Spam, позначте його як `Not spam`.
6. Не створюйте багато однакових реєстрацій поспіль.
7. Якщо лист так і не надійшов, зверніться до AWS Educate Support.

---

### Проблема: реєстрацію не прийнято через вік

AWS використовує різні minimum age requirements залежно від країни проживання.

Що зробити:

- перевірте, що країна, місяць і рік народження вказані правильно;
- не вводьте неправдивий вік;
- прочитайте актуальний розділ `Special Terms for AWS Education Programs`;
- зверніться до викладача або одного з батьків;
- за потреби зверніться до AWS Educate Support.

---

### Проблема: система пропонує AWS Builder ID

Для learner віком 18 років або старше це нормальний процес.

Для learner молодше 18 років FAQ AWS Educate описує інший процес: підтвердження email і створення пароля AWS Educate.

Що зробити:

- перевірте, чи правильно вказано рік народження;
- переконайтеся, що реєструєте learner, а не інший тип account;
- не створюйте новий account з неправдивим віком;
- якщо проблема залишається, зверніться до support.

---

### Проблема: не видно Introduction to Cloud 101

Каталог і назви курсів можуть змінюватися.

Що зробити:

1. Відкрийте `Getting Started`.
2. Увімкніть foundational або beginner filter.
3. Знайдіть курс про cloud computing fundamentals.
4. Оберіть найкоротший вступний курс.
5. Повідомте викладачу його точну назву.

---

### Проблема: course content не відкривається

Що зробити:

- вийдіть із private або incognito mode;
- оновіть сторінку;
- дозвольте pop-ups для `awseducate.com`, якщо lab відкривається в новому вікні;
- тимчасово вимкніть VPN або ad blocker;
- очистьте cache браузера;
- спробуйте актуальну версію іншого браузера;
- на телефоні спробуйте перейти на ноутбук або компʼютер.

---

### Проблема: lab session завершилася

Навчальні labs мають обмежений час.

Що зробити:

1. Поверніться на сторінку lab.
2. Перевірте, чи можна запустити нову session.
3. Почніть lab з початку або з дозволеного checkpoint.
4. Не використовуйте старі temporary credentials.
