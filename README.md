# AWS Cloud Practitioner

Курс для підготовки до сертифікації **AWS Certified Cloud Practitioner (CLF-C02)** та отримання базових практичних навичок роботи з AWS.

## Формат навчання

* Індивідуальні заняття по 60 хвилин
* Вивчення основних сервісів AWS
* Практичні завдання в AWS
* Тестові питання у форматі сертифікаційного іспиту
* Practice Exams для перевірки готовності

## Орієнтовний план

* Основи Cloud Computing та AWS
* AWS Global Infrastructure
* EC2 та обчислювальні сервіси
* S3 та зберігання даних
* RDS та DynamoDB
* IAM та основи Cloud Security
* VPC та Networking
* Lambda та Serverless
* Monitoring та CloudWatch
* Pricing, Billing та Support
* AWS Well-Architected Framework

## Очікуваний Результат

Розуміти основні принципи роботи AWS, знати ключові AWS-сервіси та бути готовим до складання іспиту **AWS Certified Cloud Practitioner (CLF-C02)**.
