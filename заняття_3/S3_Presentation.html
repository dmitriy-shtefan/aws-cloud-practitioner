03 · Пояснення · Storage Classes

Платіть за патерн доступу, а не «запас»

Що рідше потрібні дані і що довше можна чекати на їх повернення, то дешевшим буде зберігання.

S3 Standard

Частий доступ, миттєве отримання, ≥ 3 AZ.

Приклад: активний медіаконтент

Standard-IA

Рідкий доступ, але отримання відразу. Є retrieval fee.

Приклад: бекап на випадок збою

One Zone-IA

Той самий рідкий доступ, але лише 1 AZ і дешевше.

Лише для відтворюваних даних

Glacier

Архів: Flexible Archive — хвилини/години; Deep Archive — близько 12 год.

Приклад: compliance-архів на роки
Не знаєте патерн? S3 Intelligent-Tiering автоматично переміщує об’єкти між рівнями за фактичним доступом.

04 · Перевірка · Питання з Questions_3.md

Клас зберігання визначає сценарій

What differentiates Amazon S3 Standard from S3 Standard-Infrequent Access?

Standard = frequent; Standard-IA = infrequent. Обидва є об’єктними сховищами з однаковою durability.

Your company must archive some information for compliance reasons but realistically will need to access that information very infrequently. What tool exists for storing this archived information?

Glacier — архівні класи S3 для дуже рідкого доступу й довготривалого зберігання.

07 · Пояснення · Екзаменаційний компас

Три сховища — три способи мислити

Object Amazon S3
  • Key + Value + Metadata
  • API/HTTPS
  • Статичний контент, бекапи, data lakes
Block Amazon EBS
  • Віртуальний диск для EC2
  • Високі IOPS
  • Root volumes, бази даних
File Amazon EFS
  • Спільна NFS-папка
  • Кілька EC2 одночасно
  • Автоматично зростає під час запису
Ще три якорі для іспиту: S3 Standard — 11 «дев’яток» durability завдяки реплікації між AZ; overwrite PUT має strong read-after-write consistency; у класичних питаннях назва general purpose bucket має бути глобально унікальною.
