# Програма курсу «AWS Cloud Practitioner»

Курс знайомить з основними концепціями та сервісами Amazon Web Services і готує до сертифікації **AWS Certified Cloud Practitioner (CLF-C02)**.

## Заняття 1. Основи Cloud Computing та AWS

### Теми

- Що таке AWS і Cloud Computing.
- On-Premises і хмарна модель.
- Категорії хмарних послуг: IaaS, PaaS і SaaS.
- Scalability, elasticity, agility, flexibility і high availability.

### Практика

- Реєстрація та огляд навчальної платформи AWS Educate.
- Розбір перших тестових питань AWS Cloud Practitioner.

## Заняття 2. Контроль Cloud Concepts та огляд AWS Management Console

### Теми

- CapEx, OpEx, pay-as-you-go та economies of scale.
- AWS Regions, Availability Zones та Edge Locations.
- Regional і global services.
- AWS Management Console та CloudShell.
- Огляд AWS CLI, SDK та Infrastructure as Code.

### Практика

- Навігація в AWS Management Console.
- Пошук S3, EC2, Lambda та IAM.
- Вибір регіону та перевірка розташування ресурсів.

## Заняття 3. Amazon S3 та хмарне сховище

### Теми

- Object storage.
- Amazon S3 buckets і objects.
- Private і public access.
- Block Public Access.
- S3 storage classes.
- Versioning і lifecycle rules.

### Практика

- Лабораторна робота AWS Educate **Getting Started with Storage**.
- Створення S3 bucket і завантаження objects.
- Налаштування доступу до даних.
- Розміщення статичного вебсайту в Amazon S3.

## Заняття 4. Amazon EC2 та хмарні обчислення

### Теми

- Amazon EC2 instances.
- Amazon Machine Image та instance types.
- Amazon EBS volumes.
- Key pairs і Security Groups.
- Стани EC2 instance: start, stop, reboot і terminate.
- On-Demand Instances, Reserved Instances, Savings Plans і Spot Instances.

### Практика

- Лабораторна робота AWS Educate **Getting Started with Compute**.
- Створення та запуск EC2 instance.
- Перевірка AMI, instance type, EBS volume і Security Group.
- Підключення до instance та керування його станом.

## Заняття 5. AWS Lambda та Serverless

### Теми

- Server-based і serverless compute.
- AWS Lambda functions.
- Runtime, event, trigger та invocation.
- Lambda execution roles.
- Amazon CloudWatch Logs.
- Порівняння Amazon EC2 та AWS Lambda.
- Огляд Amazon API Gateway, SQS, SNS та EventBridge.

### Практика

- Створення або запуск підготовленої Lambda function.
- Виконання test event.
- Зміна відповіді функції.
- Перегляд результату виконання та CloudWatch Logs.

## Заняття 6. Networking та доставка контенту

### Теми

- Amazon VPC.
- Public і private subnets.
- Route tables, Internet Gateway та NAT Gateway.
- Security Groups і Network ACL.
- Amazon Route 53 і Amazon CloudFront.
- Огляд AWS VPN, Direct Connect, Transit Gateway і Global Accelerator.

### Практика

- Побудова схеми VPC.
- Визначення маршруту запиту від користувача до EC2 instance.
- Додавання S3 та CloudFront до схеми застосунку.
- Визначення публічних і приватних компонентів.

## Заняття 7. Бази даних, зберігання та аналітика

### Теми

- Реляційні та NoSQL databases.
- Amazon RDS, Amazon Aurora та Amazon DynamoDB.
- Multi-AZ deployment і Read Replicas.
- Порівняння Amazon S3, EBS та EFS.
- Amazon ElastiCache і Amazon Redshift.
- Огляд DocumentDB, Athena, Glue, QuickSight і SageMaker.
- Огляд AWS Backup, FSx, Storage Gateway, DataSync і Snow Family.

### Практика

- Додавання бази даних до схеми застосунку з S3, EC2 і Lambda.
- Вибір storage або database service для типових сценаріїв.
- Порівняння Multi-AZ deployment і Read Replica.

## Заняття 8. Shared Responsibility, IAM та Security

### Теми

- AWS Shared Responsibility Model.
- Security **of** the cloud і security **in** the cloud.
- Root user і MFA.
- IAM users, groups, roles та policies.
- Least privilege та IAM Identity Center.
- Encryption at rest і encryption in transit.
- Amazon CloudWatch, AWS CloudTrail та AWS Config.
- Огляд AWS KMS, Secrets Manager, Parameter Store, WAF, Shield, GuardDuty, Inspector, Macie, Security Hub і Artifact.
- AWS Organizations і Service Control Policies.

### Практика

- Аналіз відповідальності AWS і клієнта для S3, EC2 та Lambda.
- Аналіз простої IAM policy.
- Вибір security або monitoring service для типових сценаріїв.

## Заняття 9. Архітектура, вартість та підтримка

### Теми

- Шість принципів AWS Well-Architected Framework.
- AWS Cloud Adoption Framework і базові підходи до міграції.
- AWS Pricing Calculator.
- Cost Explorer, AWS Budgets і Cost and Usage Reports.
- AWS Support plans і Trusted Advisor.
- AWS re:Post, Knowledge Center та AWS Partner Network.

### Практика

- Побудова базової архітектури для бізнес-сценарію.
- Вибір інструментів оцінки та контролю вартості.
- Вибір варіанта AWS Support.

## Заняття 10. Підсумкове повторення та підготовка до CLF-C02

### Теми

- Повторення чотирьох доменів CLF-C02.
- Структура іспиту AWS Certified Cloud Practitioner.
- Multiple-choice і multiple-response questions.
- Ключові англійські слова в умовах питань.
- Типові помилкові варіанти відповідей.
- Стратегія роботи з питаннями та контроль часу.

### Практика

- Діагностичний тест за чотирма доменами CLF-C02.
- Розбір відповідей і визначення слабких тем.
- Формування персонального плану подальшої підготовки.
