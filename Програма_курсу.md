# Програма курсу «AWS Cloud Practitioner»

Курс призначений для підготовки до сертифікації **AWS Certified Cloud Practitioner (CLF-C02)** та отримання базових практичних навичок роботи з AWS.

## Формат курсу

- 10 індивідуальних занять по 60 хвилин.
- Пояснення основних концепцій і сервісів AWS.
- Практичні завдання в AWS Management Console.
- Тестові питання у форматі сертифікаційного іспиту.
- Пробний іспит і розбір результатів.

## Заняття 1. Основи Cloud Computing та AWS

### Теми

- Що таке хмарні обчислення, IaaS, PaaS і SaaS.
- Переваги AWS: еластичність, масштабованість і висока доступність.
- CapEx і OpEx, модель pay-as-you-go.
- AWS Regions, Availability Zones та Edge Locations.
- Огляд AWS Management Console.

### Практика

Зареєструвати безкоштовний learner account в AWS Educate, оглянути навчальну платформу та розпочати foundational course про AWS Cloud.

Покрокова інструкція: [Практика до заняття 1: реєстрація в AWS Educate та огляд навчальної платформи](заняття_1/Практика_AWS_Educate.md).

## Заняття 2. Безпека, IAM і Shared Responsibility

### Теми

- Модель спільної відповідальності AWS.
- Root user, IAM users, groups, roles і policies.
- Принцип найменших привілеїв.
- AWS IAM Identity Center.
- Шифрування та AWS KMS.
- Основи compliance: AWS Artifact і CloudTrail.

### Практика

Проаналізувати IAM policy та створити роль з обмеженими правами.

## Заняття 3. Обчислювальні сервіси AWS

### Теми

- Amazon EC2 та типи інстансів.
- On-Demand Instances, Reserved Instances, Savings Plans і Spot Instances.
- AMI, EBS та Security Groups.
- Elastic Load Balancing та Auto Scaling.
- Огляд ECS, EKS, Fargate, Elastic Beanstalk і Lightsail.

### Практика

Запустити EC2 instance, підключитися до нього, переглянути метрики та коректно завершити роботу ресурсу.

## Заняття 4. Зберігання даних

### Теми

- Amazon S3: buckets, objects і storage classes.
- Versioning, lifecycle policies і replication.
- S3 Glacier та архівування.
- Порівняння S3, EBS, EFS і FSx.
- Backup і disaster recovery.
- Amazon CloudFront.

### Практика

Створити приватний S3 bucket, увімкнути versioning і додати lifecycle rule.

## Заняття 5. Бази даних AWS

### Теми

- Реляційні та нереляційні бази даних.
- Amazon RDS та Amazon Aurora.
- Multi-AZ і Read Replicas.
- Amazon DynamoDB.
- ElastiCache, Redshift і DocumentDB.
- Вибір бази даних для різних сценаріїв.

### Практика

Створити DynamoDB table та виконати базові операції з даними.

## Заняття 6. Networking та доставка контенту

### Теми

- Основи Amazon VPC.
- Public і private subnets.
- Route Tables, Internet Gateway і NAT Gateway.
- Security Groups та Network ACL.
- Route 53, CloudFront і API Gateway.
- VPN, Direct Connect і Transit Gateway.

### Практика

Розібрати схему VPC та визначити маршрут запиту від користувача до застосунку.

## Заняття 7. Security та Compliance

### Теми

- AWS WAF, Shield і Firewall Manager.
- GuardDuty, Inspector, Macie та Security Hub.
- Secrets Manager і Systems Manager Parameter Store.
- AWS Organizations та Service Control Policies.
- AWS Config і принципи governance.
- Security best practices.

### Практика

Дослідити CloudTrail Event History і розібрати сценарії реагування на загрози.

## Заняття 8. Serverless, моніторинг та керування AWS

### Теми

- AWS Lambda та serverless-підхід.
- API Gateway, EventBridge, SNS і SQS.
- CloudWatch: metrics, logs та alarms.
- CloudTrail і AWS Config.
- CloudFormation та Infrastructure as Code.
- Огляд AI/ML, analytics і migration services.

### Практика

Запустити Lambda function і створити CloudWatch alarm.

## Заняття 9. Архітектура, міграція та вартість AWS

### Теми

- Шість принципів AWS Well-Architected Framework.
- AWS Cloud Adoption Framework.
- Висока доступність і disaster recovery.
- AWS Pricing Calculator.
- Cost Explorer, Budgets і Cost and Usage Reports.
- AWS Support plans і Trusted Advisor.
- Вибір сервісів для типових бізнес-сценаріїв.

### Практика

Спроєктувати просту надійну архітектуру та приблизно оцінити її вартість.

## Заняття 10. Підготовка до сертифікаційного іспиту

### Теми

- Повторення чотирьох доменів CLF-C02.
- Типові пастки у multiple-choice і multiple-response питаннях.
- Пробний тест у форматі іспиту.
- Розбір помилок і слабких тем.
- Персональний план фінальної підготовки.

### Підготовка та практика

- Перед заняттям: пройти повний пробний іспит із 65 питань.
- На занятті: проаналізувати результати та повторити теми, у яких були помилки.

## Відповідність сертифікації CLF-C02

Програма враховує офіційні ваги доменів іспиту:

- Cloud Concepts — 24%.
- Security and Compliance — 30%.
- Cloud Technology and Services — 34%.
- Billing, Pricing and Support — 12%.

Іспит містить 65 питань і триває 90 хвилин.
