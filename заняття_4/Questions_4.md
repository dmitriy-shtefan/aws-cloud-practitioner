# AWS Cloud Practitioner Questions

## What is an appropriate use case for compute-optimized EC2 instances?

- [ ] For applications requiring minimal computational resources
- [ ] For high-performance computing and batch processing workloads
- [ ] For data warehousing solutions
- [ ] For high availability web servers

## What is the primary advantage of using Savings Plans in comparison to Reserved Instances?

- [ ] Savings Plans offer more flexibility in modifying instance types.
- [ ] Savings Plans provide a higher level of capacity reservations.
- [ ] Savings Plans automatically adjust to usage changes without the need for specific instance types or Regions.
- [ ] Savings Plans have a fixed, predictable pricing model.
