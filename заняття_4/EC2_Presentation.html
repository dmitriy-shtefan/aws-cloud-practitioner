05 · Доступ, захист і стани

Key Pair відкриває вхід. Security Group контролює трафік

Key Pair

Public key — на сервері; private key .pem — тільки у вас. Для SSH: chmod 400.

Security Group

Stateful-фаєрвол інстансу: тільки Allow-правила, inbound за замовчуванням заборонений.

SSM Session Manager

Безпечніша альтернатива: без відкритого порту 22 і без локального key file.

Життєвий цикл EC2
StartЗапуск обчислень; після stop буде новий public IP.
StopТимчасово вимикає VM; EBS зберігається.
RebootПерезавантаження ОС; поточний public IP не змінюється.
TerminateБезповоротне видалення; root EBS за замовчуванням теж.
Постійна IP-адреса? Прив’яжіть Elastic IP.

07 · Моделі оплати

Ціна залежить від того, що ви готові пообіцяти

Короткостроково й непередбачувано?→On-Demand
Стабільно на 1 або 3 роки?→Reserved Instance
Зобов’язання витрачати $/hour, але потрібна гнучкість?→Savings Plans
Можна перервати за 2 хвилини?→Spot
BYOL чи вимоги до фізичного хоста?→Dedicated Host
Максимальні знижки за матеріалом
до 75%Reserved
до 72%Savings Plans
до 90%Spot
Найдешевше ≠ найкраще. Spot вимагає, щоб workload переносив переривання.

Regional RI: гнучкіша знижка без гарантії capacity.
Zonal RI: прив’язка до AZ і capacity reservation.

08 · Фінальна перевірка · Questions_4.md

Чи впізнаєте модель оплати за сценарієм?

What is the primary advantage of using Savings Plans in comparison to Reserved Instances?

Savings Plans прив’язують знижку до зобов’язання витрат, а не до окремого інстансу.

What EC2 pricing model allows you to bid on availability capacity?

Spot Instances використовують вільні обчислювальні потужності AWS зі знижкою та ризиком переривання.

You know you will need five EC2 servers for your application. The workloads will be steady and predictable. To save on costs, what pricing model should you consider?

Reserved Instances підходять для сталого й передбачуваного навантаження на 1 або 3 роки.

What instance type offers the greatest possible cost savings?

Spot дає найбільшу можливу знижку — до 90% порівняно з On-Demand.
