Компанія запускає вебзастосунок в AWS.
Є два EC2:
* Web Server — користувачі з Інтернету повинні мати до нього доступ.
* Database Server — не повинен бути доступним з Інтернету, але йому іноді потрібно виходити в Інтернет для оновлень.

У нас є VPC 10.0.0.0/16.

Потрібно визначити архітектуру і вирішити:

* Які два subnet створити і які CIDR їм дати?
* Де буде Web Server, а де Database Server?
* Де потрібен Internet Gateway?
* Де потрібен NAT Gateway?
* Що буде в 0.0.0.0/0 кожної Route Table?
