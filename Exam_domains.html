AWS Cloud Practitioner Exam Domains

A concise overview of the four exam domains, their relative weighting, and the knowledge expected in each area.

4 domains

Together accounting for 100% of the exam.

Domain 1

Cloud Concepts

24%
  • Define and explain the benefits of cloud computing, including elasticity, scalability, and agility.
  • Understand the AWS Cloud value proposition and its economic benefits.
  • Compare public, private, and hybrid cloud deployment models.
  • Identify the basic global infrastructure of the AWS Cloud.
  • Describe key concepts such as high availability and fault tolerance.

Domain 2

Security and Compliance

30%
  • Understand the AWS Shared Responsibility Model.
  • Understand access management through IAM roles, users, and groups.
  • Recognize security services such as AWS WAF, Shield, Security Hub, Macie, and GuardDuty.
  • Understand data protection mechanisms, including encryption and key management.
  • Identify AWS compliance programs and understand how AWS Artifact is used.

Domain 3

Cloud Technology and Services

34%
  • Describe the basic functions of core services, including Amazon EC2, Amazon S3, Amazon RDS, and AWS Lambda.
  • Understand AWS global infrastructure: Regions, Availability Zones, and Edge Locations.
  • Differentiate between compute, storage, database, and networking services.
  • Understand the concepts of containers and serverless computing.
  • Identify AWS service categories and their common use cases.

Domain 4

Billing, Pricing, and Support

12%
  • Understand AWS pricing models, including On-Demand, Reserved, and Spot Instances.
  • Identify key billing and cost management tools such as AWS Cost Explorer and AWS Budgets.
  • Explain the AWS Free Tier and how to track usage.
  • Understand the features of AWS Support Plans.
  • Recognize AWS Marketplace and its role in procurement.
